## 0. Prep

1. `make status` — both servers up. If not: `make start`.
2. **Fully quit the client and restart it.** `patch-Z.MPQ` changed; `/reload` does not reload an MPQ.
3. Log in as an existing level-80 character first. Nothing should break on login: no Lua error, no
   missing spells, bags intact.

Expected at login, in chat:

```
[client-patch] patch-Z.MPQ canary active: WorldMapFrame.lua loaded from patch-Z.
ServerMapPOI loaded from patch-Z.MPQ (568 static markers, Outlaw protocol v2 token required).
```

A missing first line means `patch-Z` lost the load order. A missing second line means the addon did
not load.

## 3. Dungeon XP split

Needs a character **below max level**; XP at 80 is zero. Use a leveling alt.

| Step | Do | Expect |
|---|---|---|
| 3.1 | Kill a **trash** mob in a dungeon | about **10%** of the same mob's XP outside (compare with the tooltip/base value) |
| 3.2 | Kill a dungeon **boss** (for example Taragaman in RFC) | about **33%**, roughly triple the trash rate |
| 3.3 | Kill the final boss of **Drak'Tharon Keep** (Tharon'ja) or **Halls of Stone** (Sjonnir) | **33%**, not 10% — these are the cast-credited bosses the first cut got wrong |
| 3.4 | Complete a dungeon quest | about **6x** base: the reward should read as 3 x the global 2x rate |
| 3.5 | Complete the same quest with an Ancestral Wisdom bonus active | bonus stacks on top of the 6x |
| 3.6 | Kill a mob in the open world | unchanged full rate |

If 3.3 pays 10%, stop and report: the cast-credit fix did not take effect.
